### 🚨 ERROR 3: El mito del "Ring Buffer Lock-Free" en Rust
**El Ataque (Red Team):** En `lib.rs`, tu `PmtpRing` tiene los métodos `push` y `pop` con la firma `&mut self`. 
**Un buffer lock-free NO PUEDE requerir `&mut self`.** Si requieres acceso mutable exclusivo, el compilador de Rust te está dando "lock-free" a nivel de thread, pero a nivel de concurrencia real (SPSC/MPMC), **es un mutex disfrazado**. Si dos hilos intentan hacer `push`, el borrow checker de Rust los bloqueará en tiempo de compilación. No es lock-free, es single-threaded.

**La Herida:** CHK_03 y CHK_13 (PMTP ring coherencia / False sharing guard) son falsos. No estás testeando concurrencia real, estás testeando una cola secuencial.

**La Solución (Bulldog Fix):**
Para que sea verdaderamente lock-free (SPSC - Single Producer Single Consumer), `head` y `tail` deben ser atómicos, y los métodos deben tomar `&self`. Los slots deben manejarse con cuidado.

```rust
use std::sync::atomic::{AtomicU64, Ordering};
use std::cell::UnsafeCell;

// Wrapper para permitir mutación interior segura en los slots
struct Slot<T> {
    data: UnsafeCell<T>,
}
unsafe impl<T: Send> Sync for Slot<T> {}
unsafe impl<T: Send> Send for Slot<T> {}

pub struct PmtpRing {
    head: CacheAligned,
    tail: CacheAligned,
    capacity: usize,
    // Usamos UnsafeCell para los datos, ya que la sincronización 
    // la manejan los atómicos de head/tail y sequences
    slots: Vec<Slot<Vec<f32>>>, 
    sequences: Vec<AtomicU64>,
}

impl PmtpRing {
    // ... new() igual, pero inicializando Slot { data: UnsafeCell::new(...) }

    // CORRECCIÓN: Ahora usa &self, permitiendo concurrencia real
    pub fn push(&self, tensor: &[f32]) -> bool {
        let head = self.head.0.load(Ordering::Relaxed);
        let slot_idx = (head as usize) & (self.capacity - 1);
        let seq = self.sequences[slot_idx].load(Ordering::Acquire);

        if seq != head {
            return false; // buffer lleno
        }

        // Escritura segura: solo el productor con este 'head' escribe aquí
        unsafe {
            let data_ptr = self.slots[slot_idx].data.get();
            (*data_ptr).copy_from_slice(tensor);
        }
        
        // Liberamos el slot para el consumidor
        self.sequences[slot_idx].store(head + 1, Ordering::Release);
        self.head.0.store(head + 1, Ordering::Release);
        true
    }

    pub fn pop(&self) -> Option<Vec<f32>> {
        let tail = self.tail.0.load(Ordering::Relaxed);
        let slot_idx = (tail as usize) & (self.capacity - 1);
        let seq = self.sequences[slot_idx].load(Ordering::Acquire);

        if seq != tail + 1 {
            return None; // buffer vacio
        }

        let data = unsafe {
            (*self.slots[slot_idx].data.get()).clone()
        };

        self.sequences[slot_idx].store(tail + self.capacity as u64, Ordering::Release);
        self.tail.0.store(tail + 1, Ordering::Release);
        Some(data)
    }
}
```
*Con esto, CHK_13 (False sharing) y la naturaleza lock-free son reales y verificables.*

### 🚨 ERROR 4: El Motor JAX es en realidad NumPy (y rompe el JIT)
**El Ataque (Red Team):** El archivo `3_MOTOR_JAX_CONSOLIDADO.py` promete ser la "Capa JAX".

2. Usa `hashlib.blake2b` y `np.random.default_rng` en el régimen antipodal.
**JAX NO PUEDE HACER JIT COMPILER DE `hashlib` NI DE `np.random`**. Si intentas envolver `slerp_stable` en un `@jax.jit`, el compilador de JAX lanzará un `ConcretizationTypeError` o `TracerArrayConversionError`. Además, usas importaciones relativas (`from .tsqr import...`) en un archivo monolítico, lo que lanzará un `ImportError`.

**La Herida:** No tienes diferenciación automática (`grad(slerp)`). No tienes aceleración GPU/TPU real. Tu Whitebook miente en la Capa 1.

**La Solución (Bulldog Fix):**
Si esto es JAX, debes usar `jax.random` y `jax.lax`. Si necesitas `hashlib` para el escape antipodal determinista, **debes calcular la tangente fuera del JIT** o usar una semilla fija basada en los bytes del tensor usando operaciones nativas de JAX.

Aquí está la corrección para que sea **JAX puro y JIT-teable**:

```python
import os
os.environ.setdefault("JAX_ENABLE_X64", "1")
import jax
import jax.numpy as jnp
import numpy as np
import math

# Eliminamos las importaciones relativas rotas. Todo en un solo archivo o usamos módulos reales.

@jax.jit
def slerp_stable_jax(p: jnp.ndarray, q: jnp.ndarray, t: float) -> jnp.ndarray:
    """SLERP JIT-teable. El escape antipodal usa una semilla derivada de los datos."""
    p = p / jnp.linalg.norm(p)
    q = q / jnp.linalg.norm(q)
    
    d_norm = jnp.linalg.norm(p - q)
    s_norm = jnp.linalg.norm(p + q)
    omega = 2.0 * jnp.arctan2(d_norm, s_norm)
    
    eps = jnp.finfo(jnp.float64).eps
    
    # Regimen theta ~ 0
    # Usamos jnp.where para mantener la compilación XLA (evitar python ifs)
    is_small = omega < 16.0 * eps
    lerp_result = p + t * (q - p)
    lerp_result = lerp_result / jnp.linalg.norm(lerp_result)
    
    # Regimen normal
    sin_omega = jnp.sin(omega)
    s0 = jnp.sin((1.0 - t) * omega) / sin_omega
    s1 = jnp.sin(t * omega) / sin_omega
    normal_result = (s0 * p + s1 * q)
    normal_result = normal_result / jnp.linalg.norm(normal_result)
    
    # Regimen antipodal (theta ~ pi)
    # En lugar de hashlib (que rompe JIT), usamos los bytes de 'p' para generar una semilla
    # y usamos jax.random para generar la tangente determinista.
    is_antipodal = (math.pi - omega) < 1e-9
    
    # Derivamos una semilla determinista desde los valores de 'p' (sin hashlib)
    # Multiplicamos por grandes primos y sumamos para mezclar los bits (Hashing manual JIT-friendly)
    p_ints = (p * 1e9).astype(jnp.int64)
    seed = jnp.sum(p_ints * jnp.arange(1, len(p_ints) + 1, dtype=jnp.int64))
    key = jax.random.PRNGKey(seed % (2**32))
    
    v_raw = jax.random.normal(key, shape=p.shape)
    v_raw = v_raw - jnp.dot(v_raw, p) * p # Ortogonalizar
    v = v_raw / jnp.linalg.norm(v_raw)
    
    antipodal_result = p * jnp.cos(t * math.pi) + v * jnp.sin(t * math.pi)
    
    # Selección final segura para XLA
    result = jnp.where(is_antipodal, antipodal_result, normal_result)
    result = jnp.where(is_small, lerp_result, result)
    
    return result
```

```cpp
    constexpr double EPS = 2.220446049250313e-16;

    if (std::abs(std::sin(omega)) < 1e-12) {

        double v[D];

            out[i] = p[i] * std::cos(t * M_PI) + v[i] * std::sin(t * M_PI);
        }
```

#### 2. Crea `einsof_cpp/tsqr.cpp`
```cpp
#include "tsqr.h"
#include <cmath>
#include <algorithm>
#include <numeric>
#include <stdexcept>

namespace einsof {

// Helper: Producto punto
static double dot(const double* a, const double* b, size_t n) {
    double sum = 0.0;
    for (size_t i = 0; i < n; ++i) sum += a[i] * b[i];
    return sum;
}

// Helper: Norma L2
static double norm(const double* a, size_t n) {
    return std::sqrt(dot(a, a, n));
}

// Modified Gram-Schmidt con Doble Reortogonalización (MGS2) para TSQR
void tsqr_blocked(const double* A, size_t D, size_t K, double* Q, double* R) {
    std::vector<double> V(A, A + D * K);
    
    // Inicializar R en cero
    std::fill(R, R + K * K, 0.0);

    for (size_t j = 0; j < K; ++j) {
        // Primera pasada
        double n = norm(&V[j * D], D);
        if (n < 1e-15) throw std::runtime_error("Matriz rank-deficient en TSQR");
        for (size_t i = 0; i < D; ++i) Q[j * D + i] = V[j * D + i] / n;
        R[j * K + j] = n;

        for (size_t i = j + 1; i < K; ++i) {
            double r = dot(&V[j * D], &V[i * D], D);
            R[j * K + i] = r;
            for (size_t k = 0; k < D; ++k) V[i * D + k] -= r * Q[j * D + k];
        }

        // Segunda pasada (Reortogonalización para estabilidad numérica CHK_11)
        for (size_t i = j + 1; i < K; ++i) {
            double r = dot(&Q[j * D], &V[i * D], D);
            R[j * K + i] += r;
            for (size_t k = 0; k < D; ++k) V[i * D + k] -= r * Q[j * D + k];
        }
    }
    
    // Copiar Q final (ya está en Q, pero normalizamos las columnas de V->Q por seguridad)
    for(size_t j=0; j<K; ++j) {
        double n = norm(&V[j*D], D);
        for(size_t i=0; i<D; ++i) Q[j*D + i] = V[j*D + i] / n;
    }
}

bool cholesky_qr2(const double* A, size_t D, size_t K, double* Q) {
    // Implementación simplificada de CholeskyQR2
    // G = A^T A
    std::vector<double> G(K * K, 0.0);
    for (size_t i = 0; i < K; ++i) {
        for (size_t j = i; j < K; ++j) {
            double val = dot(&A[i * D], &A[j * D], D);
            G[i * K + j] = val;
            G[j * K + i] = val;
        }
    }

    // Cholesky G = L L^T (Almacenamos L en G)
    for (size_t i = 0; i < K; ++i) {
        for (size_t j = 0; j <= i; ++j) {
            double sum = G[i * K + j];
            for (size_t k = 0; k < j; ++k) sum -= G[i * K + k] * G[j * K + k];
            if (i == j) {
                if (sum <= 0.0) return false; // No es definida positiva, fallback a TSQR
                G[i * K + j] = std::sqrt(sum);
            } else {
                G[i * K + j] = sum / G[j * K + j];
            }
        }
    }

    // Q = A * L^{-T} (Resolución hacia adelante)
    for (size_t i = 0; i < K; ++i) {
        for (size_t d = 0; d < D; ++d) {
            double sum = A[i * D + d];
            for (size_t k = 0; k < i; ++k) {
                sum -= Q[k * D + d] * G[i * K + k]; // Usando Q como buffer temporal
            }
            Q[i * D + d] = sum / G[i * K + i];
        }
    }
    return true;
}

double ortho_gap(const double* Q, size_t D, size_t K) {
    double gap_sq = 0.0;
    for (size_t i = 0; i < K; ++i) {
        for (size_t j = i; j < K; ++j) {
            double val = dot(&Q[i * D], &Q[j * D], D);
            if (i != j) {
                gap_sq += val * val;
            } else {
                gap_sq += (val - 1.0) * (val - 1.0);
            }
        }
    }
    return std::sqrt(gap_sq * 2.0); // Simetría
}

} // namespace einsof
```

```rust
use blake2::Blake2b512;
use hmac::{Hmac, Mac};
use std::sync::atomic::{AtomicU64, Ordering};

type HmacBlake2b = Hmac<Blake2b512>;

/// Verificador de integridad y anti-replay (CHK_04, CHK_14)
pub struct HmacVerifier {
    key: [u8; 32],
    last_epoch: AtomicU64,
    last_seq: AtomicU64,
}

impl HmacVerifier {
    pub fn new(key: [u8; 32]) -> Self {
        HmacVerifier {
            key,
            last_epoch: AtomicU64::new(0),
            last_seq: AtomicU64::new(0),
        }
    }

    /// Genera MAC para un payload + epoch + seq
    pub fn generate_mac(&self, payload: &[u8], epoch: u64, seq: u64) -> Vec<u8> {
        let mut mac = HmacBlake2b::new_from_slice(&self.key).expect("HMAC key error");
        mac.update(&epoch.to_le_bytes());
        mac.update(&seq.to_le_bytes());
        mac.update(payload);
        mac.finalize().into_bytes().to_vec()
    }

    /// Verifica MAC y previene replay (CHK_14)
    pub fn verify(&self, payload: &[u8], epoch: u64, seq: u64, provided_mac: &[u8]) -> bool {
        // Anti-replay estricto
        let current_epoch = self.last_epoch.load(Ordering::Acquire);
        let current_seq = self.last_seq.load(Ordering::Acquire);
        
        if epoch < current_epoch || (epoch == current_epoch && seq <= current_seq) {
            return false; // Replay detectado
        }

        let expected_mac = self.generate_mac(payload, epoch, seq);
        if expected_mac.len() != provided_mac.len() {
            return false;
        }

        // Comparación constante en el tiempo (evita timing attacks)
        let mut diff = 0u8;
        for (a, b) in expected_mac.iter().zip(provided_mac.iter()) {
            diff |= a ^ b;
        }

        if diff == 0 {
            // Actualizar estado solo si la MAC es válida
            self.last_epoch.store(epoch, Ordering::Release);
            self.last_seq.store(seq, Ordering::Release);
            true
        } else {
            false
        }
    }
}
```

```python
    # ESCAPE ANTIPODAL (JIT-FRIENDLY, SIN HASHLIB)
    is_antipodal = (jnp.pi - omega) < 1e-9
    
    # Derivamos una semilla determinista usando aritmética nativa de JAX
    # (Multiplicamos por primos y sumamos para mezclar bits, simulando un hash)
    p_ints = (p * 1e9).astype(jnp.int64)
    primes = jnp.arange(1, len(p_ints) + 1, dtype=jnp.int64) * 1000000007
    seed = jnp.sum(p_ints * primes) % (2**32)
    
    key = jax.random.PRNGKey(seed)
    v_raw = jax.random.normal(key, shape=p.shape)
    
    # Ortogonalizar v_raw contra p (Gram-Schmidt)
    v_raw = v_raw - jnp.dot(v_raw, p) * p
    v = v_raw / jnp.linalg.norm(v_raw)
    
    antipodal_result = p * jnp.cos(t * jnp.pi) + v * jnp.sin(t * jnp.pi)
    
    # Selección segura para XLA (evitar python ifs)
    result = jnp.where(is_antipodal, antipodal_result, normal_result)
    result = jnp.where(is_small, lerp_result, result)
    
    return result
```
