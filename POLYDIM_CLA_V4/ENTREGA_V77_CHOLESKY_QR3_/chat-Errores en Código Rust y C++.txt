### 🕳️ DEPTH LAYER 1: La Red (PMTP) - El DoS Silencioso y el Sesgo Fantasma

#### 1. El Ataque de Agotamiento de RAM (OOM) en el Anti-Replay
**El Ataque:**
En `PMTPAgentBridge._handle_connection`, usas `self.last_seen_seq[sender_id] = seq_num` para evitar ataques de replay. 
**ERROR FATAL:** Un atacante externo puede enviar millones de paquetes TCP con `sender_id` generados aleatoriamente (32 bytes de basura). Tu diccionario `last_seen_seq` crecerá indefinidamente hasta consumir **toda la RAM del servidor**, matando el proceso por `MemoryError`. No necesitas romper la criptografía, solo necesitas enviar basura.

**La Solución del Bulldog (LRU Cache o Poda Estricta):**
Limita el diccionario. Si un `sender_id` no se ha visto en las últimas $N$ épocas, es irrelevante.
```python
from collections import OrderedDict

class PMTPAgentBridge:
    def __init__(self, ...):
        # ...
        # FIX BULLDOG: LRU Cache para anti-replay. Máximo 10,000 peers únicos.
        self.last_seen_seq = OrderedDict() 
        self.MAX_PEERS = 10000

    def _handle_connection(self, conn):
        # ... (después de validar MAC) ...
        if sender_id in self.last_seen_seq:
            if seq_num <= self.last_seen_seq[sender_id]:
                conn.sendall(b'\x02')
                return
            self.last_seen_seq.move_to_end(sender_id)
        else:
            if len(self.last_seen_seq) >= self.MAX_PEERS:
                self.last_seen_seq.popitem(last=False) # Poda el más antiguo
        
        self.last_seen_seq[sender_id] = seq_num
```

#### 2. El Asesino de Gradientes: Redondeo Bancario en INT8

**La Solución del Bulldog (Stochastic Rounding):**

#### 6. El "Cero" en `safe_norm` y el Autodiff de JAX (Gradient Killing)
**El Ataque:**
En `safe_norm`, usas `scale = jnp.max(jnp.abs(x))`. Si `x` es exactamente cero, `scale` es 0, y `safe_scale` es 1.0. Luego calculas `norm = scale * jnp.sqrt(sq_sum)`.

```python
def safe_norm_diff(x: jnp.ndarray, axis=-1, keepdims: bool = True) -> jnp.ndarray:

    sq_sum = jnp.sum(x * x, axis=axis, keepdims=keepdims)
```

### 🕳️ DEPTH LAYER 6: El Segfault Garantizado en XLA (La Trampa del API Version)

**El Ataque:**


### 🕳️ DEPTH LAYER 7: El Agujero Negro de Gradientes Antipodales (Topología Diferencial)

**El Ataque:**
En `GeodesicKernels.log_map`, cuando dos agentes son antipodales ($x \approx -y$), el mapa logarítmico no es único. Tu código elige un vector ortogonal arbitrario `u_fallback` y hace:

**ERROR FATAL:** Al envolver `log_antipodal` en `jax.lax.stop_gradient`, has creado un **Agujero Negro de Gradientes**. Si la función de pérdida empuja a dos agentes a ser antipodales (algo común en aprendizaje contrastivo o embeddings esféricos), el gradiente de la pérdida con respecto a $x$ y $y$ será **exactamente cero**. `u_fallback` depende de `xu` (`proj_e = e_base - dot(e_base, xu) * xu`). Esta dependencia es **diferenciable y matemáticamente válida** como un subgradiente. No hay razón para cortar el grafo. Deja que JAX calcule el gradiente a través de la proyección.
```python
# FIX BULLDOG: Eliminar stop_gradient para permitir el flujo del subgradiente
# En GeodesicKernels.log_map, reemplaza la línea final:
# result = jnp.where(is_antipodal, jax.lax.stop_gradient(log_antipodal), log_normal)
```

### 🕳️ DEPTH LAYER 8: La Zona Muerta del Origen en `safe_norm` (Colapso Geométrico)

**El Ataque:**
En `safe_norm`, usas `scale = jnp.max(jnp.abs(x))`. Si `x` es exactamente el vector cero, `scale` es 0.
Luego en `log_map` y `exp_map`, haces:
```python
xu = x / jnp.maximum(safe_norm(x, keepdims=True), eps)
```
**ERROR FATAL:** Si `x` colapsa a cero (por regularización L2 o inicialización mala), `safe_norm(x)` es 0. El denominador se satura en `eps`. `xu` se convierte en `0 / eps = 0`. 
**¡`xu` ya no es un vector unitario!** Es el vector cero. Toda la geometría esférica asume que los vectores están en $S^{D-1}$. Si introduces el vector cero en `_log_map_unit`, el producto punto es 0, la distancia es 0, y el gradiente de `jnp.max` en el cero es 0. Has creado una **Zona Muerta de radio `eps`** alrededor del origen donde la geometría es plana y los gradientes mueren.

**La Solución del Bulldog (Norma Hiperbólica Suavizada):**
Abandona el truco del `max` para la normalización si necesitas que el gradiente fluya desde el origen. Usa una norma que sea estrictamente convexa y diferenciable en todo $\mathbb{R}^D$.
```python
# FIX BULLDOG: Reemplazar safe_norm por una norma L2 suavizada diferenciable en el cero
def safe_norm_smooth(x: jnp.ndarray, axis=-1, keepdims: bool = True) -> jnp.ndarray:
    eps = jnp.finfo(x.dtype).eps
    # La raíz cuadrada de (x^2 + eps^2) tiene gradiente 0 en x=0, pero no "corta" el flujo
    # matemáticamente es una hipérbola, no un cono. Nunca es cero.
    sq_sum = jnp.sum(x * x, axis=axis, keepdims=keepdims)
    return jnp.sqrt(sq_sum + eps**2)

# Y en log_map / exp_map, usa safe_norm_smooth en lugar de safe_norm para la normalización inicial:
# xu = x / safe_norm_smooth(x, keepdims=True)
```

### 🕳️ DEPTH LAYER 12: El Suicidio de Cholesky en Precisión Mixta (BF16/FP16)

**El Ataque:**
En `CliffordRotors.cholesky_qr3`:
```python
eps = jnp.finfo(W.dtype).eps
G = jnp.einsum('...ji,...jk->...ik', Q, Q) + eps * I
```
**ERROR FATAL:** Estás entrenando en una TPU o GPU con **Mixed Precision (BF16 o FP16)**, el estándar de facto para LLMs. 
Para `bfloat16`, `eps ≈ 0.0078`. Si tu matriz `W` tiene un número de condición $\kappa = 10^4$, sumar `0.0078` a la diagonal de una matriz 2x2 es **matemáticamente invisible** en BF16. `jnp.linalg.cholesky(G)` fallará, devolverá `NaN`, y tu backprop se convertirá en un mar de `NaN`s. El "Escudo Epsilon" es inútil en sub-32-bits.

**La Solución del Bulldog (Upcast Forzoso para Factorización):**
La factorización de Cholesky es inherentemente inestable en FP16/BF16. Debes subirla a FP32, factorizar, y volver a bajar.
```python
# FIX BULLDOG: Upcast a FP32 para la estabilidad de Cholesky
@staticmethod
@jax.jit
def cholesky_qr3(W: jnp.ndarray) -> jnp.ndarray:
    # Guardar dtype original
    orig_dtype = W.dtype
    
    # Subir a FP32 para el cálculo numérico crítico
    W_f32 = W.astype(jnp.float32)
    Q = W_f32
    eps_f32 = jnp.finfo(jnp.float32).eps
    I = jnp.eye(W_f32.shape[-1], dtype=jnp.float32)
    
    for _ in range(3):
        G = jnp.einsum('...ji,...jk->...ik', Q, Q) + eps_f32 * I
        L = jnp.linalg.cholesky(G)
        L_invT = jnp.linalg.inv(L.swapaxes(-1, -2))
        Q = jnp.einsum('...ij,...jk->...ik', Q, L_invT)
        
    # Bajar de nuevo al dtype original (BF16/FP16)
    return Q.astype(orig_dtype)
```

### 🕳️ DEPTH LAYER 15: El "Gimbal Lock" Esférico en los Rotores de Clifford

**El Ataque:**
En `apply_spherical_rotor`:
```python
W = jnp.concatenate([U, V], axis=-1)
W_reg = W + 1e-6 * w_norm * jnp.ones_like(W)
Q = CliffordRotors.cholesky_qr3(W_reg)
```
**ERROR FATAL:** Si `U` y `V` son linealmente dependientes (ej. `U == V` o `U == -V`, algo común en inicializaciones simétricas o colapsos de gradiente), la matriz `W` tiene **Rango 1**. 
El ruido isótropo `1e-6 * w_norm` **no es suficiente** para estabilizar una matriz de rango 1 en Cholesky. La factorización producirá una matriz `L` donde el segundo elemento diagonal es `~1e-6`. Su inversa `L_invT` tendrá elementos de `~1e6`. 
El vector `V_orth` resultante será **ruido puro amplificado por un millón**. El rotador aplicará una rotación masiva y arbitraria en la esfera. Los gradientes explotarán. Es el equivalente esférico del *Gimbal Lock*.

**La Solución del Bulldog (Ortogonalización Analítica Previa):**
No uses Cholesky para ortogonalizar 2 vectores. Es matar moscas a cañonazos y es numéricamente frágil. Usa una proyección de Gram-Schmidt analítica y estable *antes* de cualquier factorización, o perturba `V` explícitamente si es paralelo a `U`.
```python
# FIX BULLDOG: Ortogonalización analítica estable para Rango 2
@staticmethod
@jax.jit
def apply_spherical_rotor(x, U, V, theta=jnp.array(0.1)):
    eps = jnp.finfo(x.dtype).eps
    
    # Normalizar U
    U_norm = safe_norm(U, keepdims=True)
    U_orth = U / jnp.maximum(U_norm, eps)
    
    # Proyectar V fuera de U (Gram-Schmidt analítico)
    dot_UV = safe_dot(V, U_orth, keepdims=True)
    V_perp = V - dot_UV * U_orth
    
    # Si V era paralelo a U, V_perp es casi cero. Perturbar con ruido ortogonal.
    V_perp_norm = safe_norm(V_perp, keepdims=True)
    is_parallel = V_perp_norm < 1e-4
    
    # Generar un vector ortogonal a U_orth si es paralelo
    # (Truco: cruzar con la base canónica menos paralela)
    e_base = jnp.zeros_like(U_orth).at[..., 0].set(1.0)
    e_alt = jnp.zeros_like(U_orth).at[..., -1].set(1.0)
    use_alt = jnp.abs(U_orth[..., 0:1]) > 0.9
    e = jnp.where(use_alt, e_alt, e_base)
    
    # Proyectar e fuera de U_orth
    e_perp = e - safe_dot(e, U_orth, keepdims=True) * U_orth
    e_perp_norm = safe_norm(e_perp, keepdims=True)
    e_orth = e_perp / jnp.maximum(e_perp_norm, eps)
    
    # Elegir V_orth: si es paralelo, usar e_orth; si no, normalizar V_perp
    V_orth = jnp.where(is_parallel, e_orth, V_perp / jnp.maximum(V_perp_norm, eps))
    
    # ... (resto del cálculo de rotación usando U_orth y V_orth directamente) ...
```
*Nota: Esto elimina por completo la necesidad de `cholesky_qr3` en este paso específico, ahorrando FLOPs y garantizando estabilidad topológica absoluta.*

49. 🧮 safe_dot NO RESPETA EL ÁLGEBRA COMPLEJA (ERROR MATEMÁTICO GRAVE)
Ubicación: safe_dot(a, b) → jnp.sum(a * b, axis=-1)

Problema:
Para números complejos, el producto interno estándar es a · b = Σ aᵢ * conj(bᵢ) (o conj(a) * b según convención).
El código usa multiplicación directa a * b, que es el producto punto bilineal (no hermítico).
Esto rompe:

La norma safe_norm sí usa conj correctamente, pero safe_dot no.

En _log_map_unit, dot = safe_dot(x, y) se usa para calcular la proyección y - dot*x. Si x,y son complejos, el resultado no es el vector tangente correcto en el espacio de Hilbert complejo.

En apply_spherical_rotor, dot_U y dot_V son productos internos incorrectos.

Impacto:
Si algún agente usa tensores complejos (p.ej., representaciones de grupos, QM, o señales IQ), la geometría esférica no es válida y el entrenamiento diverge.

Solución:
Modificar safe_dot para que detecte el tipo complejo y use conjugación:

python
def safe_dot(a, b, keepdims=False):
    a = a.astype(jnp.float64) if not jnp.issubdtype(a.dtype, jnp.inexact) else a
    b = b.astype(jnp.float64) if not jnp.issubdtype(b.dtype, jnp.inexact) else b
    if a.dtype.kind == 'c':
        # Producto interno Hermitiano: a * conj(b)
        res = jnp.sum(a * jnp.conj(b), axis=-1, keepdims=keepdims)
    else:
        res = jnp.sum(a * b, axis=-1, keepdims=keepdims)
    return res
(Nota: En _log_map_unit, se usa proj = y - dot * x. Con el producto interno hermítico, dot es un escalar complejo, y dot*x escala el vector x. Para que proj sea ortogonal a x en el sentido hermítico, se necesita que dot = <y, x>, por lo que proj = y - dot * x es correcto si dot = conj(x) · y. Con safe_dot conjugando b, obtenemos dot = sum(a * conj(b)). Llamando a=x, b=y, obtenemos dot = x · y? No, safe_dot conjuga b, así que dot = sum(x * conj(y)) = <y, x>. Eso es correcto. Entonces proj = y - dot * x es ortogonal a x. Todo bien.)

import jax
import jax.numpy as jnp

jax.config.update("jax_enable_x64", True)

def safe_norm(x, axis=-1, keepdims=True):
    """Norma estable respetando dtype y complejos."""
    dtype = x.dtype
    axis_t = (axis,) if isinstance(axis, int) else tuple(axis)
    scale = jnp.max(jnp.abs(x), axis=axis_t, keepdims=True)
    safe_scale = jnp.where(scale == 0.0, 1.0, scale).astype(dtype)
    scaled = x / safe_scale
    if x.dtype.kind == 'c':
        sq_sum = jnp.sum((scaled * jnp.conj(scaled)).real, axis=axis_t, keepdims=keepdims)
    else:
        sq_sum = jnp.sum(scaled * scaled, axis=axis_t, keepdims=keepdims)
    norm = safe_scale * jnp.sqrt(jnp.where(scale == 0.0, 1.0, sq_sum))
    if not keepdims:
        norm = jnp.squeeze(norm, axis=axis_t)
    real_dtype = jnp.finfo(x.dtype).dtype if x.dtype.kind == 'c' else x.dtype
    return norm.astype(real_dtype)

def safe_dot(a, b, keepdims=False):
    """Producto interno Hermitiano para complejos, real para reales."""
    a = a.astype(jnp.float64) if not jnp.issubdtype(a.dtype, jnp.inexact) else a
    b = b.astype(jnp.float64) if not jnp.issubdtype(b.dtype, jnp.inexact) else b
    if a.dtype.kind == 'c' or b.dtype.kind == 'c':
        res = jnp.sum(a * jnp.conj(b), axis=-1, keepdims=keepdims)
    else:
        res = jnp.sum(a * b, axis=-1, keepdims=keepdims)
    return res

class GeodesicKernels:
    @staticmethod
    @jax.jit
    def exp_map(x, v):
        """Exponencial esférica estable."""
        eps = jnp.finfo(x.dtype).eps
        v_norm = safe_norm(v, keepdims=True)
        is_zero = v_norm < eps
        safe_v_norm = jnp.where(is_zero, 1.0, v_norm)
        v_tangent = v / safe_v_norm
        cos_t = jnp.cos(v_norm)
        sin_t = jnp.sin(v_norm)
        result = cos_t * x + sin_t * v_tangent
        result = jnp.where(is_zero, x, result)
        return result / jnp.maximum(safe_norm(result, keepdims=True), eps)

    @staticmethod
    @jax.jit
    def log_map(x, y):
        """Logarítmica esférica estable con atan2 (gradiente acotado)."""
        eps = jnp.finfo(x.dtype).eps
        xu = x / jnp.maximum(safe_norm(x, keepdims=True), eps)
        yu = y / jnp.maximum(safe_norm(y, keepdims=True), eps)

        dot = safe_dot(xu, yu, keepdims=True)
        dot = jnp.clip(dot, -1.0, 1.0)

        # FÓRMULA ESTABLE: atan2(||proj||, |dot|) evita singularidades
        proj = yu - dot * xu
        proj_norm = safe_norm(proj, keepdims=True)
        # La distancia angular: theta = 2 * atan2(||proj||, |dot|)
        # Cuando dot -> 1 (colisión), proj_norm -> 0, atan2(0, 1) = 0.
        # Cuando dot -> -1 (antipodal), proj_norm -> 0, atan2(0, 0) -> 0, pero
        # el caso antipodal se maneja con un fallback.
        theta = 2.0 * jnp.arctan2(proj_norm, jnp.abs(dot) + eps)

        # Caso antipodal exacto (fallback con vector base)
        dim = x.shape[-1]
        dist_sq = jnp.sum((xu - yu)**2, axis=-1, keepdims=True)
        is_antipodal = dist_sq > (2.0 - 1e-6)**2

        e0 = jnp.zeros_like(xu).at[..., 0].set(1.0)
        e1 = jnp.zeros_like(xu).at[..., -1].set(1.0)
        use_e1 = jnp.abs(xu[..., 0:1]) > 0.9
        e_base = jnp.where(use_e1, e1, e0)
        proj_e = e_base - safe_dot(e_base, xu, keepdims=True) * xu
        u_fallback = proj_e / jnp.maximum(safe_norm(proj_e, keepdims=True), eps)
        log_antipodal = jnp.pi * u_fallback

        # Vector tangente normalizado
        safe_proj_norm = jnp.maximum(proj_norm, eps)
        direction = proj / safe_proj_norm
        log_normal = theta * direction

        # Interpolación suave para evitar discontinuidad de gradiente (sin stop_gradient)
        blend = jax.nn.sigmoid((dist_sq - (2.0 - 1e-6)**2) * 1e6)
        result = (1 - blend) * log_normal + blend * log_antipodal

        # Caso identidad exacta (x == y)
        is_identity = dist_sq < (eps * dim)**2
        result = jnp.where(is_identity, 0.0, result)

        return result

class CliffordRotors:
    @staticmethod
    @jax.jit
    def polar_orthogonalize(W):
        """Ortogonalización por descomposición polar (SVD) – estable para K=2."""
        U, S, Vt = jnp.linalg.svd(W, full_matrices=False)
        # Proyección sobre SO(n): Q = U @ Vt
        return U @ Vt

    @staticmethod
    @jax.jit
    def apply_spherical_rotor(x, U, V, theta=0.1):
        """Rotor de Clifford estable con ortogonalización polar."""
        eps = jnp.finfo(x.dtype).eps
        U = U[..., None] if U.ndim == 1 else U
        V = V[..., None] if V.ndim == 1 else V
        W = jnp.concatenate([U, V], axis=-1)

        # Ortogonalización estable (SVD en lugar de Cholesky-QR3)
        Q = CliffordRotors.polar_orthogonalize(W)
        U_orth = Q[..., :U.shape[-1]]
        V_orth = Q[..., U.shape[-1]:]

        # Asegurar broadcasting de batch
        batch_ndim = x.ndim - 1
        if batch_ndim > 0 and U_orth.ndim == 2:
            U_orth = jnp.expand_dims(U_orth, axis=tuple(range(batch_ndim)))
            V_orth = jnp.expand_dims(V_orth, axis=tuple(range(batch_ndim)))

        dot_U = jnp.einsum('...dr,...d->...r', U_orth, x)
        dot_V = jnp.einsum('...dr,...d->...r', V_orth, x)

        c, s = jnp.cos(theta), jnp.sin(theta)
        rot_U = c * dot_U - s * dot_V
        rot_V = s * dot_U + c * dot_V

        # Broadcasting directo sin indexación extraña
        delta_U = (rot_U - dot_U)[..., None] * U_orth
        delta_V = (rot_V - dot_V)[..., None] * V_orth
        delta = jnp.sum(delta_U, axis=-1) + jnp.sum(delta_V, axis=-1)

        result = x + delta
        return result / jnp.maximum(safe_norm(result, keepdims=True), eps)

class XLAQuantizer:
    @staticmethod
    @jax.jit
    def quantize_int8_tree_reduce(tensor):
        """Cuantización simétrica INT8 en el dispositivo."""
        abs_max = jnp.max(jnp.abs(tensor))
        safe_max = jnp.where(abs_max == 0, 1.0, abs_max)
        scale = safe_max / 127.0
        quantized = jnp.clip(jnp.round(tensor / scale), -127, 127).astype(jnp.int8)
        return quantized, scale

PMTP_MAGIC = b'PMTP'
PMTP_VERSION = 4  # V77 FINAL
MAX_PAYLOAD_BYTES = 100 * 1024 * 1024  # 100 MB
MAX_SHAPE_DIMS = 8
MAX_INBOX_SIZE = 1024
NONCE_CACHE_TTL = 60  # segundos
RETRY_ATTEMPTS = 3
RETRY_BACKOFF = 0.1  # segundos base

# Header: Magic(4) Ver(1) Shape_len(1) Dtype(1) Payload_bytes(Q) Nonce(32)
#          Sender_ID(32) Session_ID(32) Seq_num(Q) Epoch(Q) Scale(d)
#          Shape(8*Q)
PMTP_HEADER_FMT = "<4s B B B Q 32s 32s 32s Q Q d " + "Q" * MAX_SHAPE_DIMS
PMTP_HEADER_SIZE = struct.calcsize(PMTP_HEADER_FMT)

# Clave HMAC (obligatoria)
PMTP_NET_KEY = os.environ.get("POLYDIM_PMTP_KEY", "").encode()
if len(PMTP_NET_KEY) != 32:
    raise RuntimeError("POLYDIM_PMTP_KEY must be exactly 32 bytes")

def pmtp_mac_chunks(sender, receiver, header, payload):
    h = hmac.new(PMTP_NET_KEY, digestmod=hashlib.sha256)
    h.update(sender)
    h.update(receiver)
    h.update(header)
    h.update(payload)
    return h.digest()[:32]

class PMTPAgentBridge:
    def __init__(self, host="127.0.0.1", port=0, agent_id=None, peers=None):
        self.host = host
        self.port = port
        self.agent_id = agent_id or os.urandom(32)
        self.session_id = os.urandom(32)  # Para reinicios
        self.peers = peers or []

        self.inbox = Queue(maxsize=MAX_INBOX_SIZE)
        self.token_bucket = None  # Opcional, se puede implementar
        self.epoch = 0
        self._epoch_lock = threading.Lock()

        self.server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        self.server_socket.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)
        self.server_socket.bind((self.host, self.port))
        self.port = self.server_socket.getsockname()[1]

        self.running = False
        self._stop_event = threading.Event()
        self._max_concurrent = threading.Semaphore(16)

        self.seq_num = 0
        self._seq_lock = threading.Lock()
        self.last_seen_seq = {}  # (sender_id, session_id) -> last_seq
        self._seq_cache_lock = threading.Lock()

        # Cache de nonces (anti-replay)
        self._nonce_cache = defaultdict(set)
        self._nonce_cache_lock = threading.Lock()

    def _clean_nonce_cache(self):
        """Limpieza periódica (llamada en cada conexión para simplificar)."""
        # En producción, usar un hilo de fondo o LRU con timestamp.
        # Aquí simplificamos: si el set crece > 1000, limpiar.
        with self._nonce_cache_lock:
            for sid in list(self._nonce_cache.keys()):
                if len(self._nonce_cache[sid]) > 1000:
                    self._nonce_cache[sid] = set()

    def start_server(self):
        self._stop_event.clear()
        self.server_socket.listen(128)
        self.running = True
        threading.Thread(target=self._listen_loop, daemon=True).start()

    def stop_server(self):
        self.running = False
        self._stop_event.set()
        self.server_socket.close()

    def _listen_loop(self):
        while not self._stop_event.is_set():
            try:
                conn, _ = self.server_socket.accept()
                if self._max_concurrent.acquire(blocking=False):
                    threading.Thread(target=self._handle_connection, args=(conn,), daemon=True).start()
                else:
                    conn.close()
            except (KeyboardInterrupt, SystemExit):
                raise
            except Exception:
                time.sleep(0.1)

    def _recv_exact(self, conn, num_bytes, timeout=10.0):
        if num_bytes > MAX_PAYLOAD_BYTES:
            raise ValueError("Payload too large")
        buf = bytearray(num_bytes)
        view = memoryview(buf)
        pos = 0
        start = time.monotonic()
        while pos < num_bytes:
            if time.monotonic() - start > timeout:
                raise TimeoutError("Deadline exceeded")
            chunk = conn.recv_into(view[pos:])
            if chunk == 0:
                raise ConnectionError("Connection closed")
            pos += chunk
        return buf

    def _handle_connection(self, conn):
        try:
            conn.settimeout(10.0)
            conn.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)

            header = self._recv_exact(conn, PMTP_HEADER_SIZE)
            fields = struct.unpack(PMTP_HEADER_FMT, header)
            magic, version, shape_len, dtype_code, payload_bytes, nonce, sender_id, session_id, seq_num, epoch, scale = fields[:11]
            shape = tuple(fields[11:11+shape_len])

            # Validaciones de seguridad
            if magic != PMTP_MAGIC or version != PMTP_VERSION:
                conn.sendall(b'\x02'); return
            if shape_len > MAX_SHAPE_DIMS or len(shape) != shape_len:
                conn.sendall(b'\x02'); return
            if payload_bytes > MAX_PAYLOAD_BYTES:
                conn.sendall(b'\x02'); return
            try:
                total_elements = int(np.prod(shape))
            except:
                conn.sendall(b'\x02'); return
            if total_elements != payload_bytes:
                conn.sendall(b'\x02'); return

            # Anti-replay con session_id
            cache_key = (sender_id, session_id)
            with self._seq_cache_lock:
                last = self.last_seen_seq.get(cache_key, -1)
                if seq_num <= last:
                    conn.sendall(b'\x02'); return
                self.last_seen_seq[cache_key] = seq_num

            # Anti-replay por nonce
            with self._nonce_cache_lock:
                if nonce in self._nonce_cache[sender_id]:
                    conn.sendall(b'\x02'); return
                self._nonce_cache[sender_id].add(nonce)
            self._clean_nonce_cache()

            # Backpressure (token bucket simplificado)
            # Aquí se podría implementar

            payload = self._recv_exact(conn, payload_bytes)

            mac_expected = self._recv_exact(conn, 32)
            mac_calc = pmtp_mac_chunks(sender_id, self.agent_id, header, memoryview(payload))
            if not hmac.compare_digest(mac_expected, mac_calc):
                conn.sendall(b'\x02'); return

            # Sincronización de época (simple)
            with self._epoch_lock:
                if 0 <= epoch < 2**63:
                    self.epoch = max(self.epoch, epoch) + 1

            # Descuantización
            try:
                quantized_arr = np.frombuffer(payload, dtype=np.int8).reshape(shape)
                arr = (quantized_arr.astype(np.float32) * scale).copy()
            except:
                conn.sendall(b'\x02'); return

            try:
                self.inbox.put_nowait((sender_id, arr))
                conn.sendall(b'\x01')
            except:
                conn.sendall(b'\x02')

        except Exception as e:
            # Loggear en producción
            # print(f"PMTP Error: {e}", flush=True)
            pass
        finally:
            conn.close()
            self._max_concurrent.release()

    def send_tensor(self, host, port, tensor, receiver_id, retries=RETRY_ATTEMPTS):
        for attempt in range(retries):
            if self._send_tensor_once(host, port, tensor, receiver_id):
                return True
            time.sleep(RETRY_BACKOFF * (2 ** attempt))
        return False

    def _send_tensor_once(self, host, port, tensor, receiver_id):
        # Cuantización en el dispositivo (GPU/TPU)
        quantized, scale = XLAQuantizer.quantize_int8_tree_reduce(tensor)
        quantized_np = np.asarray(quantized)  # Transferencia mínima (1 byte/elem)
        payload = quantized_np.tobytes()
        payload_bytes = len(payload)
        shape = quantized_np.shape
        shape_len = len(shape)
        if shape_len > MAX_SHAPE_DIMS:
            raise ValueError("Shape too large")

        with self._seq_lock:
            self.seq_num += 1
            seq_num = self.seq_num
        with self._epoch_lock:
            self.epoch += 1
            epoch = self.epoch

        nonce = os.urandom(32)
        header = struct.pack(
            PMTP_HEADER_FMT,
            PMTP_MAGIC, PMTP_VERSION, shape_len, 1, payload_bytes,
            nonce, self.agent_id, self.session_id, seq_num, epoch, scale,
            *(shape + (0,) * (MAX_SHAPE_DIMS - shape_len))
        )
        mac = pmtp_mac_chunks(self.agent_id, receiver_id, header, memoryview(payload))

        s = None
        try:
            s = socket.create_connection((host, port), timeout=5.0)
            s.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)
            s.sendall(header)
            s.sendall(payload)
            s.sendall(mac)
            ack = s.recv(1)
            return ack == b'\x01'
        except Exception:
            return False
        finally:
            if s:
                try:
                    s.close()
                except:
                    pass

```python
def safe_norm(x: jnp.ndarray, axis=-1, keepdims: bool = True) -> jnp.ndarray:
    """Norma L2 hiperbólica suavizada. Diferenciable en el cero absoluto."""
    eps = jnp.finfo(x.dtype).eps
    axis_t = (axis,) if isinstance(axis, int) else tuple(axis)
    # Usamos abs()**2 para garantizar que la norma sea estrictamente real y VJP-friendly
    sq_sum = jnp.sum(jnp.abs(x)**2, axis=axis_t, keepdims=keepdims)
    norm = jnp.sqrt(sq_sum + eps**2) 
    if not keepdims: norm = jnp.squeeze(norm, axis=axis_t)
    real_dtype = jnp.finfo(x.dtype).dtype if x.dtype.kind == 'c' else x.dtype
    return norm.astype(real_dtype)

def safe_dot(a: jnp.ndarray, b: jnp.ndarray, keepdims: bool = False) -> jnp.ndarray:
    """Producto punto seguro. Para complejos, usa la métrica Riemanniana real (Re(a*b))."""
    if a.dtype.kind == 'c' or b.dtype.kind == 'c':
        # Métrica Riemanniana subyacente para variedades complejas (CP^n)
        return jnp.sum(jnp.real(a) * jnp.real(b) + jnp.imag(a) * jnp.imag(b), axis=-1, keepdims=keepdims)
    return jnp.sum(a * b, axis=-1, keepdims=keepdims)

        Cero singularidades, gradientes fluyen en la antipodal, sin colapsar hemisferios."""

    @jax.jit

        dot_U = safe_dot(x, U_orth, keepdims=True)

        result = x + delta
        return result / jnp.maximum(safe_norm(result, keepdims=True), eps)
```

Bucle #5 — El supuesto “Zero-Singularity” tiene un bug dependiente de D

Esto es más serio que el simple problema de arcsin.

La línea:

aparece en 350.

Eso significa que el umbral de identidad es:

$$ \|x-y\| < \epsilon D $$

y no algo independiente de la dimensión.

En FP32:

$$ \epsilon \approx 1.19\times10^{-7} $$

Por lo tanto:

D = 100.000
$$ \epsilon D \approx 0.0119 $$

Cualquier diferencia angular menor aproximadamente que:

$$ 0.0119 \text{ rad}\approx0.68^\circ $$

puede ser clasificada como:

IDENTIDAD
D = 1.000.000
$$ \epsilon D \approx 0.119 $$

aproximadamente:

$$ 6.8^\circ $$

Y eso sí lo reproduje: con D=1e6, FP32 y un ángulo de solamente 0.005 rad, log_map() devolvió exactamente cero.

Eso es destrucción geométrica silenciosa.

No es una singularidad.

Es peor para entrenamiento: la función está aplanando una región entera de la esfera.

Solución

El criterio de identidad no debe crecer linealmente con D.

Debe utilizarse un umbral geométrico explícito, por ejemplo:

is_identity = dist_sq <= tau_identity**2

donde tau_identity sea una política numérica documentada y validada, no:

eps * dim

```python
class PMTPTokenBucket:
    def __init__(self, rate, capacity, max_burst):
        self.rate = rate
        self.capacity = capacity
        self.max_burst = max_burst # Ej. 5MB
        self.tokens = max_burst
        self.last_update = time.monotonic()

    def consume(self, tokens: int) -> bool:
        with self._lock:
            now = time.monotonic()
            # Solo acumular hasta max_burst, no hasta capacity, tras una pausa
            self.tokens = min(self.max_burst, self.tokens + self.rate * (now - self.last_update))

            if self.tokens >= tokens:
                self.tokens -= tokens
                return True
            return False
```
