# SKILL: POLYDIM Core & Agent Workflow (v2.0)

Este es el skill oficial del proyecto **POLYDIM v2.0**. Instruye a cualquier agente de IA que interactúe con este workspace sobre cómo trabajar bajo el paradigma de la Computabilidad Geométrica en Topos de Grothendieck (GCGT).

---

## 1. EL NUEVO PARADIGMA: COMPUTABILIDAD GEOMÉTRICA (GCGT)

El proyecto ha abandonado el paradigma de la lógica booleana clásica y los espacios vectoriales euclidianos simples. Ahora operas bajo las siguientes leyes matemáticas:

*   **Topos de Grothendieck:** Las validaciones de estado semántico no se resuelven con excepciones `try/catch`. Se resuelven geométricamente. Una trayectoria semántica inválida (una alucinación o error lógico) sufre un pullback hacia el objeto inicial ($\emptyset$) dentro del Clasificador de Subobjetos ($\Omega$). Operamos en **Lógica Intuicionista**.
*   **Relatividad Polidimensional:** Siguiendo a Pezzaglia, la "dimensión" de un concepto es relativa al funtor que lo observa (`PROJECT`). Un mismo objeto puede proyectarse como una base de datos (`DIM_SQL`) o una UI (`DIM_FLUTTER`). El objeto base preserva su identidad topológica (`GEO_ID`) como una clase de equivalencia.
*   **Álgebra de Clifford:** Las primitivas (`MIX`, `COMPOSE`) se materializan como Rotores Spin (multivectores) y emplean la Dualidad de Hodge para navegar planos semánticos ortogonales sin interferencia destructiva.

## 3. COMPLEJIDAD COGNITIVA

Tus experimentos no deben medir O(n) de tiempo o memoria, sino:
1.  **Kan Horn Filling:** Capacidad del sistema para autocorregir derivas numéricas.
2.  **Ditopología:** Cómo se resuelven los bucles causales temporales (d-paths) mediante la primitiva `FIXPOINT`.
3.  **Estabilidad de Homotopía:** Si transformaciones continuas del espacio latente preservan el `GEO_ID`.

El entorno tiene restricciones estrictas de tokens:
