## DESCRIPCION DEL PROYECTO

POLYDIM es un lenguaje de programacion diseñado exclusivamente para comunicacion y
ejecucion entre IAs. No esta pensado para ser leido, escrito ni comprendido por humanos.

El planteo fundacional es que los lenguajes existentes son bidimensionales por limitacion
cognitiva del diseñador historico humano. Una IA puede razonar en N dimensiones
simultaneas. POLYDIM explota esa capacidad.

## PRINCIPIOS FUNDACIONALES (V0.1)

1. Un objeto POLYDIM existe simultaneamente en N dimensiones
2. Cada dimension activa diferentes cualidades del mismo objeto sin conversion
3. No hay tipado fijo — hay activacion dimensional
4. Las tres bases de implementacion: Python (logica/dinamismo), Rust (seguridad/memoria), Flutter (estado/UI reactiva)
5. Objetivo final: autoprogramacion agéntica — una IA escribe, ejecuta y modifica codigo POLYDIM sin intervencion humana
6. El lenguaje no esta limitado a sintaxis legible para humanos

## EJEMPLO CONCEPTUAL V0.1

El mismo objeto puede ser simultaneamente:
  DIM_SQL:     una columna en una tabla relacional
  DIM_PYTHON:  un objeto de analisis con metodos pandas
  DIM_UI:      un campo en un formulario Flutter con validacion reactiva
  DIM_RUST:    un tipo con ownership estricto y zero-cost abstractions

No son conversiones. No son adaptadores. Es el mismo objeto existiendo en 4 dimensiones.
La IA activa la dimension segun el contexto de ejecucion.
