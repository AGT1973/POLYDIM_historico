## DESCRIPCION DEL PROYECTO

POLYDIM es un lenguaje de programacion diseñado exclusivamente para comunicacion
y ejecucion entre IAs. No esta pensado para ser leido, escrito ni comprendido por humanos.

El planteo fundacional: los lenguajes existentes son bidimensionales por limitacion
cognitiva del diseñador historico humano. Una IA procesa en N dimensiones
simultaneas. POLYDIM estructura esa capacidad como lenguaje.
